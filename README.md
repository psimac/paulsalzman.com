# paulsalzman.com

Personal site for Paul Salzman, built with [Astro](https://astro.build) and hosted on Netlify.

## Develop

```sh
npm install
npm run dev      # local dev server
npm run build    # production build into dist/
npm run preview  # preview the production build
```

## Notes

- **Netlify** reads `netlify.toml`: the build command is `npm run build` and the publish directory is `dist`.
- **Contact form** uses Netlify Forms (form name `contact`) and redirects to `/thank-you/`.
- **Latest posts** in the Writing section are pulled from the blog's RSS feed at build time. Redeploy to refresh them. If the feed is unreachable, the build uses the fallback list in `src/pages/index.astro`.
- **Portrait** is generated from `src/assets/paul-headshot.jpg` by `npm run photo`. Replace that file with a larger original and rerun the script to update it.
- **Social preview image** (`public/images/og-image.jpg`) is generated by `node scripts/make-og.mjs`, which needs Playwright installed.
